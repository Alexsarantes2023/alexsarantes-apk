## Brand & Style

This design system defines a high-performance, security-focused mobile application identity tailored for a seasoned FullStack Engineer & Cyber Security professional. Blending an elite enterprise developer aesthetic with a tactical cyber defense feel, the visual personality projects authority, mathematical precision, and technical prowess.

The design movement combines **Dark Tech Glassmorphism** and modern **Cyber-Tactical Minimalism**. Deep space-grade navy and obsidian surfaces (#0B0F19, #111827) anchor the canvas, allowing vibrant electric indigo (#6366F1), radiant cyan (#06B6D4), and defensive terminal green (#10B981) to communicate operational states, technical capabilities, and real-time interaction feedback. Subtle frosted glass cards, razor-thin translucent borders, and tactile touch zones optimize ergonomics across Android APK and native mobile form factors.

## Colors

The color architecture is built around a low-luminance, high-contrast dark foundation designed for OLED screens and extended developer terminal workflows. 

- **Primary (`#6366F1` - Electric Indigo):** Anchors core actions, brand focal points, active state highlights, and primary keyframe glows.
- **Secondary (`#06B6D4` - Cyber Teal):** Drives secondary interactions, technical metrics, payload telemetry, and active navigation indicators.
- **Tertiary (`#10B981` - Defense Green):** Applied for verified encryption statuses, secure system operational checks, and valid transaction states.
- **Neutral (`#0B0F19` - Void Obsidian):** The base background substrate. Coupled with elevated container surface `#111827`, it provides clear tonal separation without harsh contrast.
- **Domain Specializations:** Dedicated semantic slots (`accent-red-team` at `#EF4444` and `accent-blue-team` at `#3B82F6`) directly address security discipline segmentation (offensive pentesting vs. defensive architecture).

## Typography

Typography establishes an engineered, technical cadence:
- **Headline Font (Sora):** Carries futuristic geometric geometry with wide letterforms, providing high-tech punchiness to category badges, screen titles, and profile accolades.
- **Body & Label Font (Hanken Grotesk):** Provides hyper-legible, unpretentious clarity for mobile viewports, code snippets, security audit findings, and multi-line service packages.
- Tight tracking is leveraged on headlines (`-0.02em` to `-0.01em`) to create dense, commanding titles, while label scales apply loose tracking (`0.02em` to `0.05em`) in uppercase chips for tactical legibility.

## Layout & Spacing

Mobile-first ergonomics dictate a compact 8pt baseline rhythm:
- **Canvas Margins:** Fixed `1rem` (16px) outer safe-area padding ensures full-width content maximizes edge-to-edge screens without clipping on rounded corner displays.
- **Gutter:** `1rem` column gaps allow modular side-by-side metric tiles (e.g., vulnerabilities patched, tech stack cards).
- **Safe Area Insets:** Top App Bar enforces a 48px to 56px height plus platform status bar inset (`safe-area-inset-top`). Bottom navigation clears `safe-area-inset-bottom` with a fixed 64px bar height.
- **Touch Targets:** All clickable interactive elements (FAB, segmented tabs, chips, quick actions) maintain minimum hit areas of 48×48px.

## Elevation & Depth

Visual hierarchy uses layered luminescence and translucent barriers instead of conventional drop shadows:
- **Level 0 (Canvas Base):** Flat `#0B0F19` deep space background.
- **Level 1 (Sub-Surfaces):** `#111827` solid container backing for nested lists and inactive input containers.
- **Level 2 (Glassmorphic Cards):** `rgba(17, 24, 39, 0.72)` background with `backdrop-filter: blur(16px)` and a `1px solid rgba(99, 102, 241, 0.2)` border stroke.
- **Level 3 (Modal / Bottom Sheet):** `#151E32` with a cyan-tinted ambient border highlight (`rgba(6, 182, 212, 0.25)`) and 24px diffused black elevation shadow (`rgba(0, 0, 0, 0.6)`).
- **Glow Accents:** Key interactive targets (Active Tabs, WhatsApp FAB, Primary CTA) project subtle electric aura glows using 8px-16px shadow blurs matched to their accent colors at 30% opacity.

## Shapes

The design system standardizes on **Roundedness Level 2 (Rounded)**:
- Standard UI containers, cards, and input fields utilize `0.5rem` (8px) radius corners.
- Major card groupings, modals, and bottom sheets scale up to `1rem` (16px) or `1.5rem` (24px) to retain soft ergonomic containment.
- Interactive status indicators, security tags, and segmented category filters transition into complete capsule forms (`9999px` / pill) to distinctively mark tactile, toggleable objects against rectangular content blocks.

## Components

### Top App Bar & Status Bar
- Fixed top navigation with translucent obsidian glass background (`rgba(11, 15, 25, 0.85)` + blur).
- Houses the developer avatar with verified security badge indicator, profile name/title, and an icon button for quick settings or notifications.

### Segmented Pill Category Tabs
- Multi-state pill horizontal scroll container: `Web Full`, `Desk & Mob`, `Blue Team`, `Red Team`.
- Active state: `#6366F1` background with crisp white typography and a soft indigo neon aura glow.
- Inactive state: `#111827` background with subtle white hairline border (`rgba(255, 255, 255, 0.08)`) and muted text.
- Blue Team and Red Team pills incorporate dynamic accent dots (`#3B82F6` and `#EF4444` respectively).

### Cards & Service Packages
- Built with Level 2 glass surfaces, 8px corner radii, and micro-borders.
- Feature header with tech icon badge, tiered pricing chips, bulleted security deliverables with green tertiary checkmarks (`#10B981`), and a dedicated CTA trigger.

### Buttons & Inputs
- **Primary CTA:** High-contrast `#6366F1` fill with bold white label, 8px radius, and haptic feedback trigger.
- **Secondary CTA:** Translucent teal tint (`rgba(6, 182, 212, 0.12)`) with `#06B6D4` border and label.
- **Form Inputs:** `#111827` surface with a `1px solid rgba(255, 255, 255, 0.1)` border that shifts to `#6366F1` on active focus.

### Payment & Crypto Chips
- Compact modular pills displaying payment rails (PIX, Bitcoin, ETH) with monospace wallet addresses, one-tap copy buttons, and visual QR code sheet expansion triggers.

### Quick-Action Floating Action Button (FAB)
- Anchored at bottom-right (16px from edges, elevated above the bottom bar).
- Distinct WhatsApp green (`#22C55E`) circular container (56×56px) projecting a subtle green ambient luminescence (`rgba(34, 197, 94, 0.35)` blur).

### Bottom Navigation Bar
- 64px ergonomic glass shelf anchored at the bottom edge.
- Displays 4 key destinations: Overview, Services, Projects, Security Terminal.
- Active item uses an electric indigo/cyan vertical pill marker with labeled micro-typography.
